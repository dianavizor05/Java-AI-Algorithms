# AI & Optimization Algorithms (Java)

Simple console programs written in Java without external libraries. These projects were created during my Computer Science studies to practice machine learning and algorithm optimization.

## Files in this Repository
- `PerceptronIris.java` - single-layer Perceptron neural network that learns to classify Iris flowers.
- `iris.txt` - dataset used for training and testing the Perceptron.
- `KnapsackProblem.java` – solves the 0/1 Knapsack problem using two methods (Brute-Force and Greedy) and compares their execution time.
- `dane.txt` – input data (items with weights and values) for the Knapsack program.

## Tech Stack
- Java (OOP, File I/O, Collections)
